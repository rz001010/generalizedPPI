# Generalized PPI, with Application to Binary Classifier Evaluation 
Scripts for the simulations and real data analysis in "Generalized Prediction-Powered Inference, with Application to Binary Classifier Evaluation ". Preprint: [arXiv](https://arxiv.org/pdf/2602.10332).

Figures 1-6, S.1-S.9 can be generated using the scripts.

# References
The function for computing the influence function of AUC is based on the code of the cvAUC R packge here: https://github.com/ledell/cvAUC.

The real data analysis is using data from here: https://github.com/aangelopoulos/ppi_py/tree/main/examples.
