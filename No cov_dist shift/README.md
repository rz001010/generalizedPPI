# PPI estimators under no covariate distribution shift
This folder contain simulation scripts for PPI estimators under no covariate distribution shift.

Simulations in Sections 6.1, and Appendix B.4.2 - B.4.6 can be replicated using the scripts in this folder.

- Script for Section B.4.2 has code for simulations in Appendix B.4.2 and Figure S.1 is then generated using plot_mean_comp.
- Script for Section B.4.3 has code for simulations in Appendix B.4.3 and Figure S.2 is then generated using plot_tprfprauc_comp.
- Script for Section B.4.4 has code for generating Figures S.3 and S.4.
- Script for Section B.4.4 has code for generating Figures S.3 and S.4.
- Script for Section B.4.5 has code for generating Figures S.5 and S.6.
- Script for Sections 6.1 and B.4.6 has code for generating Figures 1, 2, S.7, and S.8.
